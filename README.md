# astrid-install-ci

Private scratch CI for the Astrid installer work: it gives real Windows, macOS and Linux runner results before delivery.

- Not a fork. Nothing here is linked to, or pushed to, the real banodoco repositories.
- Branches are mirrored from local work, named `agent/install/release-<n>`, `app/install/release-<n>` and `runtime/install/release-<n>`.
- Pushes happen only at the end of each release and after review fix rounds.
- Delete this repository once the work has been delivered.
